## How to use it — 20 min, weekend day 2

1. Scan **top-down** for the first **two** rows marked ⬜ or 🔴.
2. Open each note **at its Self-Test**. Answer cold, on a blank page.
3. **Do not re-read the note.** Failed a question? Read *that section only*, then move on.
4. Update **Last tested** + **Confidence**, and write what beat you in the last column.

🎯 Re-reading feels productive and isn't. **The only line in this file that builds memory is step 2.**

**Confidence key:** ⬜ never tested · 🔴 failed / shaky · 🟡 got most of it · 🟢 solid, from memory

> A 🟢 doesn't retire a topic — it just sends it to the back. Retest anything 🟢 after ~6 weeks; that's roughly where free recall starts to go without a refresh.
